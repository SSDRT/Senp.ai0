# Pelvis-axis knee projection: prospective development screen

29 October2026. The preceding passive audit found ten withheld correct-labelled squats with knee-driver far-side disagreement, while their hip samples stayed within the current acceptable bands. This experiment tests whether a directly observed pelvic-axis projection changes that mismatch. It does not widen the reference range or reinterpret the labels.

Define the lateral direction by RASI minus LASI. Project the selected ASI-minus-knee and ankle-minus-knee rays onto the plane orthogonal to that direction and measure the angle between those projections. Retain both rays' out-of-plane angles and projected-length fractions. Both pelvic markers, selected knee and selected ankle must be directly present; degenerate rays/axis remain missing. Withhold the driver if either projected fraction is below0.25. No repaired marker, inferred hip centre, bone constraint, global-up assumption, source-peak normalization or alternate-axis search is permitted. This is a surface-marker plane surrogate, not an anatomical sagittal/valgus angle or MP33 measurement.

The alternative hip-centre regression route was reviewed but is not used: the [pyCGM2 implementation](https://pycgm2.github.io/pyCGM2/modules/model/generated/pyCGM2.Model.modelDecorator.harringtonRegression.html) depends on calibration inputs and marker/plate settings absent from this corpus. Its defaults are not measurements of these participants. The [primary hip-centre study](https://pmc.ncbi.nlm.nih.gov/articles/PMC5121588/) also distinguishes skin-marker and bony-landmark measurements. No third-party regression code, unmeasured anthropometric value or new predicted coordinate is ingested.

Freeze code and input receipts before reading outcomes. Use all16 continuous original development recordings /160 unchanged labels, subjects01-04 only. Compare the rejected frontal-arm measurement as the control against that same arm measurement plus the new m01 knee projection. Preserve every m07 input/attempt/verdict, the source01/reference02 exception, original100Hz times, LEFT squat and RIGHT shoulder selection, and all compiler `/9` thresholds/calibration gates. No source label enters a frame or selects a reference. Both discarded plane components remain available as separate research descriptors and never silently become qualified evidence.

This is a measurement ceiling screen. Both0.70 recall and0.80 assessable coverage on the entire development denominator are required before considering a separately frozen full form-discrimination policy. Projection alone cannot certify squat frontal-plane form or shoulder abduction form, even if a numerical gate happens to pass. All0.90 precision/0.70 recall/0.80 coverage gates and a complete form policy are required before any validation. Failure stops this candidate before quality-head fitting. No validation05-07/final08-10, new annotation, production code/weight/threshold/native change or APK is permitted here. Existing readiness remains50/100 and this screen earns zero points.
