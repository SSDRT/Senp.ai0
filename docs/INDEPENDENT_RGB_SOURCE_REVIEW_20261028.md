# Independent RGB source and label-scope review

28 October 2026. This bounded publisher review addresses the independent RGB evidence gap. It does not alter the live/reference engine, train network weights, evaluate camera rep accuracy or add readiness points. Current verified implementation remains `6d1386b` (compiler `/8`), with readiness **50/100**.

## Publisher findings

- [Fitness-AQA](https://github.com/ParitoshParmar/Fitness-AQA) explicitly limits its dataset to non-commercial purposes and requires an access request. It is not ingested for this open application workflow. No request or message is sent.
- The original [FLEX paper link](https://arxiv.org/abs/2506.03198) now resolves to the publisher's [MyoMechanix repository](https://github.com/HaoYin116/MyoMechanix). Its current data terms restrict access to approved non-commercial academic/research use and prohibit redistribution. Public paper/code availability does not replace the data terms. No dataset is downloaded.
- [EgoExo-Fitness](https://github.com/iSEE-Laboratory/EgoExo-Fitness) displays an Apache code licence while separately requiring a signed dataset agreement. The intake records that unresolved data grant rather than inferring media rights from the code badge. The public agreement document is preserved; no agreement is signed, access request submitted or raw data ingested.
- [FitAQA](https://huggingface.co/datasets/Kelly0510/FitAQA) releases annotations/documentation under Apache 2.0 and explicitly excludes and does not relicense source videos. Its multiple-choice items assess particular form aspects; answering one aspect correctly is not a complete-rep correctness label. Temporal error intervals do not provide exhaustive repetition boundaries or label their complement as correct. The documented schemas also lack a subject roster suitable for an audited subject-disjoint split. No Parquet label data, source videos or inferred correct-rep labels are ingested.
- FitAQA links to [Qualcomm QEVD](https://www.qualcomm.com/developer/software/qevd-dataset). The publisher's [data research licence](https://www.qualcomm.com/content/dam/qcomm-martech/dm-assets/documents/Dataset-Research-License-Feb-25-2025.pdf), sections 1–3, restricts the data and resulting models to its specified internal research scope. Apache-licensed annotations or loader software do not replace that separate grant. No QEVD data is downloaded or used for tuning. Other FitAQA media sources remain unverified; this review makes no blanket claim about their individual assets.

These findings concern the captured publisher versions. They do not establish that no eligible independent RGB source exists elsewhere. The FitAQA taxonomy is potentially useful background, but this review adds no expert degree/time thresholds to the app and does not convert text into training trajectories.

## Implemented safeguard and verification

`scripts/audit_independent_rgb_sources.py` performs an offline metadata/scope precheck. Specific data restrictions take precedence over general code/annotation grants. Aspect-question answers and temporal-error intervals remain distinct from whole-rep labels; a video hash cannot replace rep boundaries and subject identity. Even a declared complete-rep schema still requires an original source, rights, split and label audit before evaluation. The helper awards no points and never changes the scorer or accepts a corpus automatically.

All **131 Python checks** pass, including seven new source/scope regressions. The current 1,796 scored evidence receipts and unchanged rubric revalidate at 50/100. Production main sources match the verified implementation exactly. Earlier 292 JVM, both 30-case native suites, 2,688 controls and 124 corruption results remain scoped to the unchanged engine and are not represented as new runs. No RGB extraction, timestamped frame change, new annotation, final UI-PRMD subject access or APK occurs in this metadata-only checkpoint.

Publisher metadata, licence documents, HTTP/source/hash receipts, the offline audit and test log are preserved in an immutable local checkpoint. See `models/independent-rgb-source-review.provenance.json`. Continue licensed continuous-reference acquisition and independent generalization work under a prospective protocol; do not substitute QA accuracy, an error-free interval, code licensing or a readiness score for human-rep precision.
