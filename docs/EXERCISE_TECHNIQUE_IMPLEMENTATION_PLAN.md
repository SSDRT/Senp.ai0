# Exercise-specific live pose tuning

Continue `codex/live-pose-accuracy` from `e0503cc`. Scope: pose features, on-device classification, exercise technique rules and live feedback composition. No frontend redesign.

1. Review primary exercise instructions (NHS, NASM, ACE and Google). Keep concise original fact summaries, source URL/date and the measurement mapping. Do not scrape/repackage full copyrighted articles or imply all internet guidance has been exhausted. Reject inconsistent boilerplate and distinguish observable geometry from breathing, activation, load, contact and fine-spine claims.
2. Add a versioned exercise/variant catalogue with source-backed targets, reference-calibrated movement constraints and explicit unsupported checks. Numeric trigger margins remain engineering defaults unless the source actually specifies the number. Rules require confirmed exercise selection and recognized phases; unknown variants retain generic reference coaching.
3. Compile selected technique policies into the existing confidence-gated live coach. Preserve per-joint confidence, mirror semantics, source/subject/gap resets, per-phase dwell/hysteresis and bounded memory. Do not label every difference from a demonstration as bad technique or overwrite the phase recognizer's reference with rule targets.
4. Train a small downstream pose-state classifier from the official Google ML Kit pose CSV (812 labelled samples, four squat/push-up states), after pinning and checking its license/provenance. Export deterministic compact parameters and an image-grouped holdout report. Missing subject identities, source model differences and absent negative classes limit claims. This is actual downstream classifier fitting, not text-only retraining of BlazePose landmark weights. Keep automatic exercise-based corrections opt-in pending independent validation.
5. Download the CC BY 4.0 Mendeley seven-exercise video corpus (DOI 10.17632/kgbb3yn47p.3), verify ZIP member CRCs and retain per-video SHA-256. Preserve all 33 landmarks and source timestamps while extracting pinned MediaPipe Full world geometry at about 500 ms intervals, at most the first 24 seconds per clip. Inspect representative timestamped overlays. Whole-clip good/bad labels are weak supervision, not expert fault timings.
6. Attempt seven compact logistic quality classifiers from 2.4-second confidence-masked windows (25 features, q10/median/q90/availability). Split by participant, using seed 20261022: 16 training, five validation, five test participants. Fit normalization/imputation on training only; give each training video equal total weight. Select research thresholds using validation participants only (at least 95% window precision, ten flags, two participants and three clips). Abstain on missing evidence, incompatible landmark model or outliers. If a split lacks reliable examples/classes, export an unsupported record instead of fitting it. Report test precision/recall, coverage, camera views and video-level scores, including poor results. These diagnostics remain optional and release-unapproved and never generate anatomical instructions. Production `needsReview` also requires release approval. Do not tune on the held-out test set.
7. Test catalogue integrity, rule targets and variant exceptions, phase applicability, unsupported measurements, mirrors, missing joints, temporal boundaries, contradictory reference targets, classifier numerical parity/unknown inputs and Android packaging/integration. Run existing engine checks, native tests and compatibility verification. Commit source and deliver the catalogue, source matrix, both training reports, APK and reproducible evidence.

The catalogue has 54 explicit exercise/variant IDs. Of 41 sources, 40 provide exercise guidance; the dataset source supplies identity/label provenance for standing side bend, not a technique prescription. General reference comparison remains available outside this catalogue but does not imply exercise-specific validation.

Training the landmark network itself still requires appropriately licensed annotated images/videos and a separate image training/evaluation pipeline. Written technique descriptions supply supervision for rule design, not image/keypoint ground truth.

## Execution outcome

Implemented the catalogue, policy binding, live seams, trained state classifier, reproducible video extraction and six fitted research quality classifiers. All 1,042 video members were extracted; 44,985 frames yielded 21,128 eligible windows. Push-up quality fitting was refused because there were zero eligible validation windows. Held-out quality results did not establish readiness for production coaching; all learned quality review flags remain disabled. Detailed metrics, tests and remaining qualification work are in `EXERCISE_TECHNIQUE_VALIDATION.md` and `models/exercise_quality.training-report.json`. No thresholds were retuned against test participants.
