# Additional independent RGB-label sources reviewed

Checked 24 October 2026. This is a source/licence/annotation review, not training or an accuracy result. No footage or held-out trajectories from these additional sources were ingested. A publicly readable page or repository is not itself an unrestricted data licence. Existing UI-PRMD final subjects 08–10 remain sealed.

| Original source | Relevant evidence | Current decision for this application |
|---|---|---|
| [REHAB26-ViewAngles](https://zenodo.org/records/23018128) | RGB, original MediaPipe33 trajectories and physiotherapist per-rep segmentation/correctness; squat and arm abduction are relevant. | Publisher explicitly restricts use to academic/non-profit, non-commercial research. Not ingested under the current free/open application workflow, consistent with the earlier REHAB24-6 decision. |
| [Fitness-AQA](https://github.com/ParitoshParmar/Fitness-AQA) | Fine-grained workout form annotations; squat and overhead press are relevant. | Publisher requires an access request and non-commercial use. No request submitted and no data used. |
| [FLEX paper](https://arxiv.org/abs/2506.03198) and [current MyoMechanix repository](https://github.com/HaoYin116/MyoMechanix) | Multi-view fitness quality assessment and structured error annotations. | Current linked repository requires approved institutional research access, prohibits commercial use/redistribution, and says code/models are forthcoming. Not a freely ingestible dataset for this app. |
| [CFRep](https://github.com/lc-leonardo/CFRep) | Eight participants, rep-validity labels for squat, deadlift and double-unders. | README calls it open access, but the recursive repository tree exposes no LICENSE/COPYING/terms file. Unrestricted permission is unverified. Only squat maps directly to a current qualified policy. No training or label inspection performed. |
| [ExeCheck](https://www.cs.bu.edu/faculty/betke/ExeChecker/) | Seven subjects, paired correct/incorrect RGB-D exercise recordings and rep segmentation. | Public project page links a Dropbox folder but does not state a dataset reuse licence. Permission remains unverified; no dataset downloaded or access message sent. |
| [MobiPhysio data descriptor](https://pmc.ncbi.nlm.nih.gov/articles/PMC12992533/) | Smartphone exercise videos, subject IDs and expert questionnaire scores. | Descriptor describes scores for complete multi-repetition videos, including repetition-number/speed factors. These cannot be silently converted into per-rep correctness labels. Article CC-BY terms do not by themselves establish the separate dataset's terms. Not used for the binary per-rep gate. |

The RGB independent-label gate therefore remains unmet. This review does not prove no suitable dataset exists; it records why these specific candidates were not adopted. Do not substitute whole-video labels, participant expertise or MediaPipe self-agreement for per-repetition human-form truth. Do not contact authors or submit institutional/access declarations without explicit user authorization. Continue useful engine, reference and runtime work while retaining this evidence gap.
