# Current-frame IMAGE and person-crop extraction research

This 25 October candidate changes the measurement pipeline rather than sampling density. The fixed sixteen 15 FPS reference recordings already contain all original frames in their established complete caches. The experiment keeps those timestamps and the pinned Full network, and compares two new ways of processing the same RGB: independent full-frame IMAGE inference, and IMAGE inference on a person crop derived solely from the current coarse VIDEO observation. This is reference-only research; no source outcomes or independent held-out subjects enter candidate selection.

[The official MediaPipe guide](https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker/python) documents separate IMAGE and VIDEO modes, tracking in video/live operation, and image plus metric world landmark outputs. The image depth convention is described in the [upstream pose documentation](https://github.com/google-ai-edge/mediapipe/blob/master/docs/solutions/pose.md). The hypothesis is that an independently detected current frame or a more explicit person region may avoid some tracking/background errors. This is an inference to test, not an established accuracy gain.

Both variants require the current coarse shoulders/hips at the existing 0.65 confidence gate. The crop variant additionally requires current wrists/ankles in-frame at that confidence, derives bounds from observed confident points, expands each span by 20%, clips only the input pixel rectangle, and requires at least 64 pixels per edge. Missing crop evidence produces a missing candidate observation; it is not filled from previous or future frames. The refiner's shoulder/hip centre must agree with the current coarse person's centre within half the coarse torso length, with a 0.05 normalized-image floor. This is a limited geometric identity guard, not biometric identification or proof that an existing coarse track never changes people.

Retain all 33 raw local image/world/visibility/presence values from each model result, including withheld results. Record the exact crop bounds, input RGB hash and original PTS. For admitted observations, invert crop image x/y to original normalized image coordinates; image z scales by crop width/original width. Preserve metric world coordinates, visibility and presence exactly. Do not clamp or repair predicted landmarks. The two explicit preprocessing fingerprints prevent accidental mixing with established inputs. Kotlin independently verifies the inverse mapping and unchanged world/confidence fields before calibration.

The protocol must freeze source/coarse-cache hashes, model identity, modes, geometric gates, variant/fit priority and source-code receipts before inference. Code receipts normalize line endings; binary/data receipts use exact bytes. Readiness weights, the 32-reference denominator, six policies and every production angle/range/dwell/noise/confidence/coverage/reconstruction threshold remain unchanged. Existing four-stage backend choices retain priority. New full IMAGE ordinary, crop IMAGE ordinary, full IMAGE bounded, then crop IMAGE bounded candidates are considered only for previously unavailable reference sides.

Inspect original timestamped RGB with coarse, full-image and crop-image overlays. A reference self-reconstruction improvement alone is not rep precision or a readiness gain. Any useful candidate still needs a coherent source pipeline, causal/source regression and independent evaluation, native verification and an APK before promotion. No app production code changes are part of this initial screen. At the freeze the 42.5/100 readiness and verified APK remained current; the decision follows below. Final skeletal subjects 08–10 remain sealed.

## Outcome reviewed 27 October: no additional usable references

Code and protocol were committed in `f702bfc` before inference. Both variants completed on all sixteen complete references: 7,191 original timestamps each, 14,382 candidate observation slots. The extraction took 260.45 seconds of wall time with three desktop workers; this is not phone inference performance. All 128 reference/side/variant/fit trials used unchanged production calibration gates and passed the raw-coordinate mapping checks.

| Variant | Original frame slots | Admitted to the same-frame coarse person | Raw model results retained | Ready sides: ordinary / bounded |
|---|---:|---:|---:|---:|
| Full IMAGE | 7,191 | 5,311 | 5,886 | 4 / 3 |
| Coarse-guided crop IMAGE | 7,191 | 1,859 | 1,940 | 0 / 0 |

The reconstructed IMAGE references were already served by established backends. **Zero** new reference/side configurations are recovered. The established 12/32 registry remains unchanged and both variants are rejected for promotion. The frame-admission figures are preprocessing/provenance diagnostics, not correct-rep recall or human-form precision. No source rep replay or independent-label evaluation is run for these failed candidates.

Crop ordinary and bounded trials each have 23 missing-feature, seven insufficient-cycle and two failed-reconstruction outcomes. Full IMAGE ordinary has eleven missing-feature and seventeen insufficient-cycle failures; bounded additionally loses one ordinary-ready side to reconstruction failure. Requiring a reliable current person prevents unsupported crops, but causes substantial missing evidence. The retained projection/feedback runtime warnings do not establish calibrated monocular 3D geometry or a speed/accuracy benefit.

Six original timestamped RGB frames and eighteen model diagnostic panels were inspected, including overlays where a raw pose exists and explicit withheld/missing results. At the fixed side-squat and push-up frames the crop branch is withheld; full IMAGE still observes a pose. In the front squat at 6,000 ms the crop branch is also withheld, despite full IMAGE binding to the coarse person. A crop derived only from confident points may omit useful head/limb context. These observations do not create correctness labels or justify lowering the confidence gate. A different future crop-extent design would require a new frozen experiment, with raw provenance preserved.

Verification passes 222 core-motion JVM and 77 Python cases, including cross-language mapping/world/confidence and timestamp rejection checks. Main production sources remain identical to verified engine `c610706`; earlier native/control evidence remains intact and is not represented as a new run. There is no new APK, network-weight change, raw established-cache rewrite, source-outcome parameter search or final-subject access. Readiness remains **42.5/100**, with live human-rep precision unknown. See `models/image-reference-extraction.provenance.json` for the frozen inputs, reports, source and test receipts.
