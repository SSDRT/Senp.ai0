# Native delegate timing and evidence probe

27 October 2026. The verified app still defaults to CPU inference, with a separately supported optional GPU/fallback path. This experiment measures that existing path before considering any runtime change. Current engineering readiness is **50/100**; this probe earns no performance or accuracy points.

Freeze `models/native-delegate-probe-protocol.json`, the exact research-only APK, original upstream fixture, pinned Full/Heavy assets, auditor and source before inference. The additional test source is included only through `scripts/live-delegate-probe.init.gradle`; normal builds and the existing native suites do not include this diagnostic class. No production module, model weight, reference selector or threshold changes.

Use two separately booted task-owned API 35 x86_64 AVDs in fixed order: SwiftShader software graphics, then host graphics. Android's [emulator acceleration documentation](https://developer.android.com/studio/run/emulator-acceleration) distinguishes the requested graphics modes. Record actual SurfaceFlinger renderer, boot properties and startup failures; a requested host mode does not prove which renderer/delegate executed. MediaPipe's [official Android example](https://github.com/google-ai-edge/mediapipe-samples/blob/main/examples/pose_landmarker/android/app/src/main/java/com/google/mediapipe/examples/poselandmarker/PoseLandmarkerHelper.kt) explains GPU owner-thread requirements. The unchanged Senpai adapter creates, infers and closes on one thread.

For each graphics environment, run eight fixed conditions: Full/Heavy × original static pose/black image × requested CPU/GPU. Each has two warmup and eight measured calls on a fresh graph. Synthetic diagnostic timestamps advance by 67 ms; they are not original exercise-video timestamps. Retain every result, not the fastest run. Record creation time separately, total synchronous call time including bitmap ownership/mapping, native detect time, actual delegate, fallback reason, reset counters, model identity and all observed MP33 image/world/confidence fields. Empty mapper placeholders must not become observed landmarks.

The auditor requires all conditions, exact asset/model identities, original native fields, positive finite timings and complete streams. CPU fallback is never reported as GPU acceleration. Compare matching static-pose fields using the existing 1e-6 native parity tolerance, retaining any differences without repair or wider tolerance. Render the original fixture beside Full/Heavy CPU/GPU overlays with actual delegates clearly labelled. No exercising-person, correct/incorrect-rep, camera-clock, frame-admission or ten-minute throughput claim can be inferred from these short static streams.

Even a faster actual GPU with matching static output is only a follow-up candidate. Promotion would still require original timestamped exercise input, causal/reference/independent regressions, native validation and an actual camera measurement under the unchanged rubric. A missing or slower GPU is retained as a negative result and does not justify changing the default. Final subjects remain sealed; no source videos or independent trajectories are accessed by this probe.
