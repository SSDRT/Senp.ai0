# Development-only frontal arm measurement

29 October2026. The current surface-marker ABC shoulder angle mixes elevation and movement out of the torso plane. The central-torso driver improved development recall but failed the frozen gates. This experiment tests a different, explicitly named measurement: the unsigned elevation of the observed upper-arm vector projected onto the observed torso frontal plane. It is not an anatomical angle, native Euler-column interpretation or MP33 measurement.

Define down from the shoulder midpoint to the pelvis-marker midpoint. Orthogonalize the observed right-minus-left shoulder vector against down to define lateral, and their cross product defines the plane normal. Use the original selected elbow-minus-shoulder vector. The projected angle is atan2(abs(lateral component),down component),0-180 degrees. Retain the original out-of-plane angle and projected-length fraction as separate descriptors. All four torso markers and the selected elbow must be finite, nonzero and nondegenerate. If the projected fraction is below0.25, withhold the projected driver while retaining the observed out-of-plane component. No fallback, interpolation, source-peak normalization or inferred joint is allowed.

Freeze code and all input receipts before reading development outcomes. Export the original16 full recordings and160 unchanged publisher episodes from subjects01-04, and replay baseline and projection through the same compiler `/9` with unchanged defaults. Use the original reference-subject rule and fixed RIGHT shoulder / LEFT squat mappings. Only m07's driver slot receives the explicitly named projection in the research replay; every m01 frame/attempt must remain identical. Keep raw marker XYZ and original angle fields unchanged. Auxiliary plane/fraction descriptors are not silently added to the production qualified rule. Inspect episode1 original start, projected maximum and end for the fixed s01 correct, s02 incorrect and s04 correct recordings, including a missing original start.

This first screen measures the recall/coverage ceiling of that projection and its errors, including every incorrect/unmatched attempt. It cannot certify abduction form because projection discards a measured normal component; an explicit out-of-plane form constraint would be required before promotion. Do not claim improved clinical/camera precision by hiding that component. If recall or assessable coverage fails the existing0.70/0.80 development gates, stop this candidate before any additional quality-head fitting. Even passing those two gates would require a separately frozen full form-discrimination candidate and all0.90 precision /0.70 recall /0.80 coverage gates before validation. No validation05-07, final08-10, app source, native inventory, production model, threshold or delivery APK changes are authorized by this research screen.

The data remain the original UI-PRMD PDDL release and position-marker ordering already verified against the [publisher descriptor](https://pmc.ncbi.nlm.nih.gov/articles/PMC5773117/). NumPy and existing pure Kotlin causal replay are used; no new dataset or annotation is acquired. This experiment earns zero readiness points and provides no human live-rep precision.
